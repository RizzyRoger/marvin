Privacy

Voice audio stays on this device. Chat text is stored locally. Optional cloud features send only what you enable:

  • Cloud LLMs (Settings → AI Providers): prompts and replies
  • Web Search (Tavily): search queries derived from your request
  • Spotify: OAuth tokens in Keychain; playback commands to Spotify

Obsidian notes stay on disk by default. If you use a cloud model while Obsidian tools are active, note text included in that turn can leave this machine to the provider. Prefer local Qwen for vault-heavy work, or disconnect the vault when using cloud models.

Clear chat history?

This removes every message from Marvin’s chat history. This cannot be undone.

Delete voice profile?

This permanently deletes your enrolled Voice Lock profile. You will need to re-enroll to use Voice Lock again.

Reset all samples?

This discards every enrollment recording in progress. Your saved voice profile is not deleted until you choose Delete voice profile.
