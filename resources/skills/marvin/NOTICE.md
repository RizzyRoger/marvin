# Marvin feature skills

Authoritative Agent Skills for Marvin-specific dialects (not third-party Obsidian formats).

| Skill | Default | Role |
|-------|---------|------|
| `daily-tasks` | On | Checkbox / TODO lines that vault task tools can parse |
| `web-search` | On | Query + citation discipline for `web_search` |

These are prompt guidance only. Executable behavior stays in `backend/tools/`.

Skipped on purpose (covered by tool schemas / always-on style): Spotify, timers,
voice scrambler, switch_model, Voice Lock, python runner, spoken TTS style.
